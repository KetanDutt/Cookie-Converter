Where do I get these cookies?
  1. Sign in to gemini.google.com in your browser.
  2. Export them any of these ways: an exporter extension (Netscape .txt or JSON), or DevTools → Network → right-click a request → Copy as cURL.
  3. Drop the file here or paste it above, then press Convert (Ctrl+↵).
