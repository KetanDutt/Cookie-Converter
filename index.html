        How to get your cookies

        Three routes, and five input formats. Signed in at gemini.google.com is the one part that matters.

        1. 01

          Copy a request as cURL

          Open DevTools (F12) → Network, reload, then right-click a gemini.google.com request → Copy → Copy as cURL. Paste the whole command above.

        2. 02

          Or export a cookie file

          Get cookies.txt LOCALLY (Chrome, Edge) or cookies.txt (Firefox) export the current site. #HttpOnly_ lines are cookies, not comments. Cookie-Editor's JSON export works too.

        3. 03

          Convert, copy, delete

          Check the six required cookies below, copy cookie.json — or cookie.txt for --cookie-file — into gemini-web2api, then delete both the export and the payload.

        Getting your Gemini cookies

        Five export methods — pick whichever fits the tools you already have.

        No extensions, nothing to install — the fastest route.

        1. Stay signed in at gemini.google.com.
        2. Open DevTools (F12) → Network and reload the page.
        3. Right-click the first gemini.google.com request → Copy → Copy as cURL.
        4. Paste the whole command into the converter.
        curl 'https://gemini.google.com/app' \
  -H 'cookie: SID=…; HSID=…; SAPISID=…'

        Best if you convert often.

        1. Install Get cookies.txt LOCALLY (Chrome/Edge) or cookies.txt (Firefox).
        2. Open gemini.google.com and stay on that tab.
        3. Export cookies for the current site, then drop the .txt file above.

        #HttpOnly_ lines are expected — they are cookies, not comments.

        Cookie-Editor and friends produce this shape.

        1. On gemini.google.com, open Cookie-Editor → Export → Export as JSON.
        2. Paste the array — or use DevTools → Application → Cookies → Copy all as JSON.
        [{ "domain": ".gemini.google.com", "name": "SID",
   "value": "…", "expirationDate": 1893456000 }]

        For copying values by hand.

        1. DevTools → Application → Cookies → https://gemini.google.com.
        2. Copy the six values: SID, HSID, SSID, APISID, SAPISID, __Secure-1PSID.
        3. Paste them as one line: SID=…; HSID=…; SSID=…; APISID=…; SAPISID=…; __Secure-1PSID=…

        Values containing spaces mean a copy slipped — re-copy the cell.

        Straight from response headers or a server log.

        1. DevTools → Network → pick a request → Response Headers.
        2. Copy every Set-Cookie line and paste them above.

        Attributes (Domain, Path, Expires, SameSite) are parsed, not mistaken for cookie names.
